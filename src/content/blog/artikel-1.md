Perjalanan saya sebagai developer dimulai dari nol. Tidak ada background IT, tidak ada mentor — hanya rasa ingin tahu yang kuat dan koneksi internet yang cukup.

## Awal Mula

Saya belajar HTML pertama kali dari tutorial YouTube di malam hari setelah pulang kerja. Layout sederhana, tanpa framework, tanpa build tool. Tapi di situlah semua dimulai.

[Panduan Core Web Vitals](/blog/panduan-core-web-vitals)

Setelah HTML, saya melanjutkan ke CSS, lalu JavaScript. Setiap langkah terasa berat, tapi juga terasa seperti membuka pintu baru ke dunia yang jauh lebih luas.

## Menemukan Astro

Setelah mencoba berbagai framework — dari plain JS, React, sampai Next.js — saya menemukan **Astro**. Pendekatannya yang *content-first* dan filosofi *zero JS by default* langsung membuat saya jatuh cinta.

Astro memungkinkan saya membangun website yang **sangat cepat**, [Dokumentasi Astro](https://astro.build) ramah SEO, dan tetap fleksibel ketika dibutuhkan interaktivitas.

## Pelajaran Penting

- **Konsistensi mengalahkan intensitas.** Belajar 1 jam setiap hari lebih efektif dari marathon 10 jam seminggu sekali.
- **Bangun sesuatu yang nyata.** Tutorial hanya titik awal — project nyata adalah guru terbaik.
- **Komunitas sangat penting.** Discord, GitHub Discussions, dan forum seperti Dev.to mempercepat proses belajar luar biasa.

Perjalanan ini belum selesai — dan justru itulah yang membuatnya menarik.
